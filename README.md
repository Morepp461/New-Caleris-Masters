# CALERIS MASTERS

A motorsport roleplay web game.

## Development

```bash
npm install
npm run dev
```

Create `.env.local` from `.env.example` and configure the MongoDB connection before enabling database-backed features.

## Product direction

CALERIS MASTERS is being rebuilt as a game platform, not an administration spreadsheet. The foundation will be developed in deliberate stages: public game world, identity and roles, teams and drivers, competition seasons, race engine, then the connected economy.
